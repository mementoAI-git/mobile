# Android Native Voice Playback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run the same C++ voice playback engine on Android that iOS already uses, so Android gets gapless playback, de-click fades, the adaptive buffer and concealment instead of the JavaScript buffer queue.

**Architecture:** `modules/react-native-memento-voice` gains an `android/` library. CMake compiles the existing `common/cpp/mementovoice` sources and links them against `react-native-audio-api`'s prefab package, the same C++ audio graph the iOS pod uses. A Kotlin TurboModule's synchronous `install()` hands the JSI runtime pointer to a JNI function. That function calls the existing `installVoicePlaybackBindings`. On the JavaScript side, only a platform check changes.

**Tech Stack:** Android Gradle Plugin with prefab, CMake, NDK, Kotlin, JNI, JSI, Expo prebuild (Continuous Native Generation: `android/` is gitignored and regenerated).

**Strategy:** `api/docs/superpowers/specs/2026-09-30-voice-experience-strategy.md`, Phase 1c.

## Global Constraints

- **Proven build.** On 2026-09-30 these exact files were built into a debug APK from a copy of this repo: `./gradlew :app:assembleDebug -PreactNativeArchitectures=arm64-v8a`, React Native 0.86.3, `react-native-audio-api@1.0.0-nightly-3310950-20260927`. The APK contained `libmementovoice.so`. It needed `libreact-native-audio-api.so` and exported `Java_io_mymemento_voice_MementoVoiceAudioModule_nativeInstall`, and all 17 audio-api symbols it imports resolved. Behavior on a physical device was not tested.
- **Independent of the other voice plans.** It works before or after them. The quality plan's C++ changes apply to both platforms automatically.
- `android/` at the repo root is generated by `npx expo prebuild`. Never hand-edit it. Every Android change goes through `app.json`, a config plugin, or the module's own `android/` folder.
- **How to apply edits.** "In `<file>`, find:" plus a code block, then "Replace it with:" plus a code block. The find text appears exactly once. Copy exactly. "Create `<file>`:" writes a new file with exactly that content. If a find text is missing, stop and report.

### Task 1: Fix Android builds (missing splash drawable)

Every Android build of this app currently fails at `:app:processDebugResources` with "resource drawable/splashscreen_logo not found". `expo-splash-screen`'s theme always references that drawable, but only generates it when the plugin has an `image`, and Memento's splash is plain white. A config plugin writes an empty white drawable. `expo-splash-screen` deletes existing splash images in its own step, and Expo runs these steps in reverse plugin order. So this plugin must be listed **before** `expo-splash-screen`, so that it runs after it.

**Files:**
- Create: `plugins/with-blank-splash-logo.js`
- Modify: `app.json`
- Test: `src/features/chat/native-voice-runtime-contract.test.ts`

const fs = require('fs');
const path = require('path');
const { withDangerousMod } = require('expo/config-plugins');

// expo-splash-screen's Android theme always references @drawable/splashscreen_logo,
// but only generates it when the plugin has an `image`. Memento's splash is a
// plain white screen, so provide an empty white drawable instead.
const BLANK_SPLASH_LOGO = `<?xml version="1.0" encoding="utf-8"?>
<shape xmlns:android="http://schemas.android.com/apk/res/android" android:shape="rectangle">
  <solid android:color="#FFFFFF" />
  <size android:width="1dp" android:height="1dp" />
</shape>
`;

module.exports = function withBlankSplashLogo(config) {
  return withDangerousMod(config, [
    'android',
    async (modConfig) => {
      const drawableDir = path.join(
        modConfig.modRequest.platformProjectRoot,
        'app/src/main/res/drawable',
      );
      fs.mkdirSync(drawableDir, { recursive: true });
      fs.writeFileSync(path.join(drawableDir, 'splashscreen_logo.xml'), BLANK_SPLASH_LOGO);
      return modConfig;
    },
  ]);
};
```

#include <jni.h>
#include <jsi/jsi.h>

#include "mementovoice/VoiceSessionHostObject.h"

extern "C" JNIEXPORT void JNICALL
Java_io_mymemento_voice_MementoVoiceAudioModule_nativeInstall(
    JNIEnv * /*env*/,
    jobject /*thiz*/,
    jlong runtimePointer) {
  auto *runtime = reinterpret_cast<facebook::jsi::Runtime *>(runtimePointer);
  if (runtime == nullptr) return;
  mementovoice::installVoicePlaybackBindings(*runtime);
}
```

Create `modules/react-native-memento-voice/android/src/main/java/io/mymemento/voice/MementoVoiceAudioModule.kt`:

```kotlin
package io.mymemento.voice

import com.facebook.react.bridge.ReactApplicationContext
import com.facebook.react.module.annotations.ReactModule

@ReactModule(name = MementoVoiceAudioModule.NAME)
class MementoVoiceAudioModule(
  reactContext: ReactApplicationContext,
) : NativeMementoVoiceAudioSpec(reactContext) {
  override fun getName(): String = NAME

  // Runs synchronously on the JS thread, so touching the runtime here is safe.
  override fun install(): Boolean {
    val runtimePointer = reactApplicationContext.javaScriptContextHolder?.get() ?: return false
    if (runtimePointer == 0L) return false
    nativeInstall(runtimePointer)
    return true
  }

  private external fun nativeInstall(runtimePointer: Long)

  companion object {
    const val NAME = "MementoVoiceAudio"

    init {
      // Our library links against react-native-audio-api's shared library.
      System.loadLibrary("react-native-audio-api")
      System.loadLibrary("mementovoice")
    }
  }
}
```

package io.mymemento.voice

import com.facebook.react.BaseReactPackage
import com.facebook.react.bridge.NativeModule
import com.facebook.react.bridge.ReactApplicationContext
import com.facebook.react.module.model.ReactModuleInfo
import com.facebook.react.module.model.ReactModuleInfoProvider

class MementoVoiceAudioPackage : BaseReactPackage() {
  override fun getModule(name: String, reactContext: ReactApplicationContext): NativeModule? =
    if (name == MementoVoiceAudioModule.NAME) MementoVoiceAudioModule(reactContext) else null

  override fun getReactModuleInfoProvider(): ReactModuleInfoProvider =
    ReactModuleInfoProvider {
      mapOf(

            MementoVoiceAudioModule.NAME,
            MementoVoiceAudioModule.NAME,
            false, // canOverrideExistingModule
            false, // needsEagerInit
            false, // isCxxModule
            true, // isTurboModule
          ),
      )
    }
}
